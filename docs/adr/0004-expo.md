# ADR 0004: Expo Router + React Native

- 상태: Accepted
- 결정일: 2026-10-06

## 맥락

모바일은 native navigation, 화면 및 보호된 credential storage가 필요하다. DOM UI 공유는 플랫폼 차이를 숨길 수 있다.

## 결정

Expo SDK 57과 Expo Router, React Native 0.86.3 및 SDK 권장 React/TypeScript를 고정한다. contracts/api-client/auth 경계는 공유하고 화면은 React Native로 작성한다. native token store는 expo-secure-store를 사용한다.

## 대안

별도 Swift/Kotlin은 팀의 TypeScript 재사용 목표에 비용이 크다. bare React Native 대신 Expo tooling을 기본으로 사용하되 필요한 native 기능이 생기면 development build로 검증한다.

## 영향

SDK와 Router/native dependency는 독립적으로 임의 업그레이드하지 않는다. expo install --check와 export를 확인하고 SecureStore와 native navigation은 실제 simulator/emulator에서 검증한다. web fallback은 memory token store다.
